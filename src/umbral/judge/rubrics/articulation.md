# Rúbrica — Fase 1: Articulación

Evalúa: `spec-*.md`

## Criterios para `complete`:
- Al menos 2 casos borde específicos del dominio (no genéricos)
- Modos de falla con consecuencia descrita
- Alcance delimitado (qué SÍ y qué NO)
- Datos de entrada identificados
- Calibración por rol:
  - Explorer: casos prácticos orientados al usuario
  - Navigator: invariantes del sistema
  - Anchor: trade-offs arquitectónicos

## Criterios para `incomplete`:
- Casos borde genéricos (ej: "qué pasa si falla la red")
- Modos de falla sin consecuencia
- Alcance no delimitado
- Datos de entrada no identificados

## Criterios para `needs_revision`:
- La spec es solo una lista de features
- No hay casos borde
- Ambigüedades sin resolver
