# Rúbrica — Fase 3: Construcción

Evalúa: coherencia EDE vs código

## Criterios para `complete`:
- Nombres y conceptos de la EDE reflejados en el código
- Sin scope creep (el código no hace más de lo que dice la EDE)
- Restricciones del "Qué No Hacer" respetadas
- Nota: en v0.1.0 sin integración Git, evaluación liviana

## Criterios para `incomplete`:
- El código no refleja los conceptos de la EDE
- Scope creep detectado
- Restricciones violadas

## Criterios para `needs_revision`:
- El código diverge significativamente de la EDE
- No hay EDE aprobada para este bounded context
