# Rúbrica — Fase 4: Verificación

Evalúa: `checkpoint-*.yaml`

## Criterios para `complete`:
- Checkpoint presente con preguntas y respuestas
- Respuestas con contenido real (no monosílabos ni repeticiones)
- Autoevaluación coherente con el contenido de las respuestas

## Criterios para `incomplete`:
- Checkpoint presente pero respuestas superficiales
- Autoevaluación no coherente
- Faltan preguntas para conceptos clave

## Criterios para `needs_revision`:
- No hay checkpoint
- Respuestas vacías
- Evidencia de copy-paste sin comprensión
