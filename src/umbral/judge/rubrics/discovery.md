# Rúbrica — Fase 0: Discovery

Evalúa: `discovery-notes.md` + `domain-map.yaml`

## Criterios para `complete`:
- El problema está descrito sin jerga técnica
- El usuario objetivo está identificado
- El Mapa de Dominio es coherente con la escala
  - learning: 3-5 conceptos
  - mvp: 5-8 conceptos
  - startup: 8-12 conceptos
- El estado actual del problema está descrito

## Criterios para `incomplete`:
- El problema menciona tecnología específica sin justificación
- Falta identificar al usuario objetivo
- El Mapa de Dominio tiene menos conceptos que el mínimo para la escala
- La descripción es vaga o genérica

## Criterios para `needs_revision`:
- La descripción es una lista de features, no un problema
- No hay Mapa de Dominio
- Los conceptos del dominio no son relevantes al problema
