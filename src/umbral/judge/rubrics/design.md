# Rúbrica — Fase 2: Diseño

Evalúa: `.umbral/edes/*.md`

## Criterios para `complete`:
- EDE Nivel 1: 2 componentes con contenido concreto
- EDE Nivel 2: 4 componentes con ADR y alternativa descartada
- EDE Nivel 3: tool bindings, ADR formal, blast radius, governance
- Las decisiones son específicas (no declarativas sin justificación)

## Criterios para `incomplete`:
- Componentes presentes pero con contenido genérico
- ADR sin alternativas evaluadas
- "Por Qué" sin justificación real

## Criterios para `needs_revision`:
- Componentes vacíos o placeholder
- Contradicciones con EDEs existentes
- Nivel de EDE no corresponde al rol del usuario
